# Design concepts 03: ₦17,000 print tees (24 Oct 2026)

Front-and-back mockups for a new line of ₦17,000 oversized tees, generated with GPT Image 2.5 on Higgsfield. They follow the owner's reference board: a small chest mark with a big back print, grey line art, one accent colour (red, sand-gold or chrome), kanji, tonal glyphs, chrome flames, outline lettering and a spec sheet.

Everything is original Final Heaven material. Several references were other people's IP (Solo Leveling, Berserk's brand mark, the Spider-Man spider, Porsche), so only their visual language is used, never their characters, symbols or names. The three-star mark came from `brand/logo/mark-black.png` as a reference.

These are mockups, not print files. Chosen designs need clean, high-resolution or vector artwork, with the logo taken from `brand/logo/`.

Known issues before any of these go further:
- **tee-11**: the grey graffiti behind the angel looks like made-up characters next to the real kanji. Redraw it as an abstract tag or as "FINAL HEAVEN" in graffiti.
- **tee-12**: "Fear is loud. Faith is quiet." and "Quiet heaven atmosphere" are copy I wrote. They need the owner's approval.
- **tee-17**: the outline letters have a faint grey drip fill. Decide whether to keep it or print a clean single line.
- **tee-18**: the small paragraph is "lorem ipsum" placeholder text and needs real copy. The bike stats belong to a fictional bike ("FH-07 SERAPH"), not a product claim.
- **All**: kanji 天国 means "heaven" (tengoku); check it with a native reader before printing.
