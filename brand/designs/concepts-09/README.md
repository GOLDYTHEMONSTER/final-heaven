## Refined versions (`refined/`)

The owner's picks, on acid-fade tees with a small mark at the bottom left of the front and the print kept inside the shirt body: `main-character-acid-black`, `race-07-acid-stone`, `grain-profile-acid-black`, `retro-sun-acid-brown`, `orange-grove-acid-sand`, `tiger-acid-black`.

Still open on these:
- **race-07:** the car is less specific now but still reads like a real 1970s coupe. Have it redrawn before production.
- **orange-grove:** the vines cross the letters, which makes FINAL HEAVEN harder to read. Keep them behind the type in the artwork.
- **grain-profile:** the mark sits close to the portrait's shoulder, so give it more room.
- **main-character:** the "plot armour included" caption was removed to follow the no-caption rule.
- **All:** acid-fade blanks need sourcing, and the mottled fabric must be checked on a test print, especially where the print leaves the shirt showing through.

## Notes on the first versions

Before any of these go further:
- **All:** these are 1k mockups. Chosen designs need flat artwork at print size, with the real mark from `brand/logo/`.
- **tee-21:** one moth carries a skull marking, which leans gothic. Swap it if unwanted. The big letters need checking for stiffness.
- **tee-22:** this has the finest detail. The grain must be redrawn with dots large enough to print, then test printed. The figure is invented and must stay that way. It also needs regenerating on the store background to match the others.
- **tee-23:** the car looks like a real 1970s model and the red and blue stripes look like a known racing livery. Redraw both so they're generic before production.
- **tee-25:** the finest lines are in the vines and blossom stamens. Thicken them to the line minimums.
- **tee-26:** check that the tiger's fur has no soft grey shading. It needs to be solid lines or dots.
- **tee-21, 22, 26:** on black tees, remove the black from the print file so the shirt shows through.
