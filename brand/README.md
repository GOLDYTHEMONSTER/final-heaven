# Final Heaven brand

The logo sheet and ready-to-use logo files. Open **logo-sheet.pdf** (or `.png`) to see every version and the rules for using them.

| File | Use it for |
|---|---|
| `logo-sheet.pdf` / `.png` | The full sheet, to share with printers, designers or partners |
| `logo-sheet.html` | The editable source of the sheet (open in Chrome, print to PDF) |
| `logo/lockup-horizontal-white.png` / `-black.png` | Default logo: website, emails, receipts, packaging |
| `logo/lockup-stacked-white.png` / `-black.png` | Square or tall spaces: bags, labels, posters |
| `logo/wordmark-white.png` / `-black.png` | Name only, when the mark is already nearby |
| `logo/mark-white.png` / `-black.png` | The mark alone: tags, stickers, social avatars |
| `logo/mark-neon.png` | Neon mark, transparent; dark backgrounds only |
| `logo/mark-neon-on-ink.png` | Neon mark on the brand black, ready to post |
| `logo/app-icon-512.png` | App and social profile icon |
| `logo/apple-touch-icon-180.png` | iPhone home-screen icon |
| `logo/favicon-32.png` | Browser tab icon |
| `source/logo-*-original.png` | The original full-size artwork, untrimmed |

White files go on dark backgrounds, black files on light ones. All PNGs have transparent backgrounds except the app icons and `mark-neon-on-ink.png`.

The website itself uses its own copies in `public/brand/`; changing files here doesn't change the site.

**Colours:** Ink `#0A0A0B` · Paper `#F2F1EE` · Ember `#E8613C` (accent) · Muted `#A3A3A8` · Neon pink `#FF3D9A` and cyan `#38D6FF` (neon mark only).
**Type:** Archivo, ExtraBold 800 at 125% width, uppercase, for the wordmark and headings.
