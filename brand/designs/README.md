# Design concepts: tees and hoodies (22 Oct 2026)

Concept mockups for new back prints, generated with GPT Image 2.5 on Higgsfield. They take the visual language of trending streetwear graphic tees (big back print, mixed type, a short quote, a strong colourway) and use only Final Heaven's own material. Every garment keeps the three-star mark on the front; only the back changes.

These are mockups, not print files. Chosen designs need clean, high-resolution or vector artwork before production, and the logo should come from `brand/logo/`, not from these renders.

Known issues before any of these go further:
- **tee-01**: the poem lines ("some angels don't leave / they just wait in silence until you find them again") were written by the model. They need the owner's approval.
- **tee-02**: the sneakers resemble Air Jordan 4s. Redraw them as generic sneakers to avoid Nike trade-dress problems.
- **hoodie-02**: a dove covers the F so the word reads "A_TERLIFE", and there are red smudges on the lettering. Regenerate it.
- **hoodie-04**: the mark inside the badge is slightly distorted. Use the real logo file in production.
